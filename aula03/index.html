ARRAYS • CONCEITO

Arrays

Em JavaScript, um array é uma estrutura de dados usada para armazenar uma coleção de elementos. Esses elementos podem ser de qualquer tipo de dados, incluindo números, strings, objetos, ou até mesmo outros arrays. Diferente de algumas outras linguagens de programação, os arrays em JavaScript são dinâmicos, ou seja, o tamanho do array pode ser alterado dinamicamente conforme a adição ou remoção de elementos.

PRÁTICA • MAP E FILTER

Exercício prático

Exercício de map e filter: combine map e filter para transformar um array de strings em maiúsculas e, em seguida, filtrar apenas as que começam com uma letra.

map-filter.js
</> JavaScript 
// Definindo um array de strings
let palavras = ["maçã", "banana", "morango", "abacaxi", "melancia"];

// Usando map para transformar todas as strings em maiúsculas
let palavrasMaiusculas = palavras.map(function(palavra) {
    return palavra.toUpperCase();
});

// Definindo a letra inicial para o filtro
let letraInicial = "M";

// Usando filter para selecionar apenas as strings que começam com a letra "M"
let palavrasFiltradas = palavrasMaiusculas.filter(function(palavra) {
    return palavra.startsWith(letraInicial);
});

// Imprimindo o resultado final
console.log(palavrasFiltradas);

function aprovacao(numero1, numero2, numero3) {
    let media = (numero1 + numero2 + numero3) / 3;

    if (media >= 7) {
        return "Aluno(a) Aprovado(a)!";
