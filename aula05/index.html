ARQUITETURA

Arquitetura

Vue segue o padrão de arquitetura orientada a componentes, com influências do padrão MVVM (Model-View-ViewModel).

Frameworks
2026.2
ARQUITETURA • MVVM

Camadas do MVVM em Vue

Model — os dados da aplicação (state, props, dados vindos de APIs)
View — o template HTML renderizado na tela
ViewModel — a instância do componente Vue, que conecta Model e View através da reatividade
Frameworks
2026.2
ARQUITETURA • FLUXO

Como as peças se conectam

O Model guarda o estado (data)
O Vue observa esse estado (sistema de reatividade)
Quando o estado muda, a View é atualizada automaticamente
Interações do usuário na View (cliques, digitação) disparam métodos que alteram o Model
O ciclo se repete. É um fluxo de dados reativo em duas direções

SPA

SPA — Single Page Application

Aplicação web que carrega uma única página HTML e atualiza o conteúdo dinamicamente conforme o usuário interage, sem recarregar a página inteira.

Frameworks
2026.2
SPA • FUNCIONAMENTO

Como funciona

O navegador carrega o HTML, CSS e JS uma vez
A navegação entre "telas" é simulada via JavaScript (manipulação do DOM e/ou roteamento no cliente)
Comunicação com o servidor ocorre em segundo plano, geralmente via APIs (REST, GraphQL), trocando apenas dados (JSON)
Frameworks
2026.2
SPA • COMPARAÇÃO

SPA vs. aplicação tradicional (MPA)

Aspecto Multi-Page (MPA) SPA
Navegação Recarrega a página inteira Atualiza apenas o necessário
Requisições HTML completo a cada rota Apenas dados (JSON)
Experiência Mais "picotada" Fluida, como um app nativo
SEO Nativamente melhor Exige estratégias extras (SSR, prerender)

DATA BINDING • TWO-WAY

Two-way binding (v-model)

O dado flui nos dois sentidos: a View atualiza o Model e o Model atualiza a View. Muito usado em formulários.

DATA BINDING • REATIVIDADE

Reatividade por trás do data bind

Vue 3 usa Proxies do JavaScript para detectar mudanças nos dados automaticamente
Não é preciso "avisar" o Vue manualmente quando um dado muda, ele detecta e re-renderiza sozinho
Essa é a base que torna o data binding possível e transparente para quem programa
