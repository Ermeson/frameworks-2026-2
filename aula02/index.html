VARIÁVEIS • TIPAGEM DINÂMICA

Tipagem em JavaScript

JavaScript é uma linguagem de tipagem dinâmica e fraca

Não é necessário declarar o tipo de uma variável.
Todas as variáveis são objetos (referência).
Números são todos reais de 64 bits.
A variável "altera" o seu tipo conforme os valores forem atribuídos:
tipagem.js
</> JavaScript 
var x;         // x é indefinido
x = 5;         // x é um número
x = "John";    // x é uma string
x = true;      // x é um booleano
x = null;      // x é nulo

VARIÁVEIS • VAR, LET E CONST

Variáveis

Diferentemente de outras linguagens, como Java, no JavaScript não há necessidade de declarar o tipo da variável — mas isso não significa que ela não tem tipo. Na verdade, o JS faz a tipagem dinamicamente, de forma similar ao PHP.

Vale lembrar que podemos declarar uma variável no JavaScript com três operadores: var, let e const. De acordo com o ECMA2015, utilizar o operador var se tornou uma má prática.

ESCOPO • VAR

Escopo de bloco

Variáveis declaradas com var têm escopo de função ou escopo global.
São visíveis dentro da função em que foram declaradas ou em todo o programa, se declaradas fora de qualquer função.
● Funciona!
escopo-var.js
</> JavaScript 
function minhaFuncao() {
  for (var i = 0; i < 5; i++) {
    console.log(i);
  }
  console.log(i); // i ainda é acessível aqui devido ao escopo de função do 'var'
}

minhaFuncao();

Escopo de bloco

Variáveis declaradas com let são "içadas" para o começo do bloco em que são definidas.

  }

CONTROLE DE FLUXO • IF

Estruturas de decisão

A principal estrutura de decisão é o comando IF (SE).
O IF verifica o resultado do teste lógico.
Se verdadeiro, executa os comandos entre chaves { }.
Se falso, pula para a próxima instrução após o IF.

CONTROLE DE FLUXO • TESTE LÓGICO

O que é teste lógico?

O comando IF necessita de uma expressão que retorne verdadeiro (true) ou falso (false) — geralmente uma comparação usando operadores lógicos.

CONTROLE DE FLUXO • IF ELSE

If Else

Podemos incrementar o comando IF com o uso do ELSE — "caso contrário / se não".
Os comandos do IF são executados somente quando o teste for verdadeiro.
Os comandos do ELSE são executados sempre que o teste tiver resultado falso.
if-else.js
</> JavaScript 
if (teste_logico) {
  // comandos a serem executados se o teste for verdadeiro
} else {
  // comandos a serem executados se o teste for falso
}

DESAFIO 02 • RESOLUÇÃO

Vamos codar (Resolução)

Dias da semana com switch case.

dias-semana.js
</> JavaScript 
let numero = 2;

switch (numero) {
  case 1: document.writeln('Domingo'); break;
  case 2: document.writeln('Segunda-feira'); break;
  case 3: document.writeln('Terça-feira'); break;
  case 4: document.writeln('Quarta-feira'); break;
  case 5: document.writeln('Quinta-feira'); break;
  case 6: document.writeln('Sexta-feira'); break;
  case 7: document.writeln('Sábado'); break;
  default: document.writeln('O número está fora do intervalo.');
}
