03 — VARIÁVEIS

Variáveis e constantes

É muito importante em uma linguagem de programação poder armazenar dados de forma temporária — essa é a função das variáveis. Sempre que precisar armazenar uma informação, vamos usar as variáveis: podemos inserir, remover ou alterar informações nelas. Vamos ver como usar esse recurso fundamental.

03 — VARIÁVEIS

JavaScript é Case Sensitive

Case Sensitive significa algo como “sensível à caixa das letras” ou “sensível a maiúsculas e minúsculas”.

const Fruta = "Banana"  // é diferente de
const fruta = "Maçã"
03 — VARIÁVEIS

Tipagem em JavaScript

JavaScript é uma linguagem de tipagem dinâmica e fraca
➜
Não é necessário declarar o tipo de uma variável
➜
Todas as variáveis são objetos (referência)
➜
Números são todos reais de 64 bits
➜
A variável “altera” seu tipo conforme os valores atribuídos
var x;         // x é indefinido
x = 5;         // x é um número
x = "John";    // x é uma string
x = true;      // x é um booleano
x = null;      // x é nulo
03 — VARIÁVEIS

Var

Declarar variáveis em JavaScript é bem simples: diferente de linguagens tradicionais como C++, não informamos o tipo de dado e, por isso, não precisamos de operações como typecast. Basta usar a palavra reservada var e o nome da variável.

<!doctype html>
<html lang="pt-br">
<head>
  <title>Curso de Javascript</title>
  <meta charset="UTF-8">
  <script>
    var jogador;
    var vidas;
    var municao;
  </script>
</head>
<body>
</body>
</html>
03 — VARIÁVEIS

Atribuição de valores

Veja que a atribuição é simples: usamos o operador = e, como já foi destacado, se o valor inserido for um texto, deve vir entre aspas "texto".

<script>
  var jogador = "Bruno";
  var vidas = 3;
  var municao = 100;
</script>
03 — VARIÁVEIS

Variáveis

Diferentemente de outras linguagens, como Java, no JavaScript não há necessidade de declarar o tipo da variável — mas isso não significa que ela não tem tipo. Na verdade, o JS faz a tipagem dinamicamente, de forma similar ao PHP.

Vale lembrar que podemos declarar uma variável em JavaScript com três operadores: var, let e const. De acordo com o ECMA2015, utilizar o operador var se tornou uma má prática.

03 — VARIÁVEIS

Escopo de bloco

FUNCIONA

Variáveis declaradas com var têm escopo de função ou escopo global — ou seja, são visíveis dentro da função em que foram declaradas ou em todo o programa, se declaradas fora de qualquer função.

function minhaFuncao() {
  for (var i = 0; i < 5; i++) {
    console.log(i);
  }
  console.log(i); // i ainda é acessível aqui
}

minhaFuncao();
03 — VARIÁVEIS

Escopo de bloco

ERRO

Variáveis declaradas com let são “içadas” para o começo do bloco em que são definidas — isso também é conhecido como hoisting.

function minhaFuncao() {
  console.log(i); // ReferenceError:
  // 'i' não está acessível
  // antes de sua declaração

  for (let i = 0; i < 5; i++) {
    console.log(i);
  }
}

minhaFuncao();
03 — VARIÁVEIS

Escopo de bloco

Variáveis declaradas com let são “içadas” para o começo do bloco em que são definidas (hoisting) — e isso muda o comportamento da redeclaração.

✓
Permite redeclaração — var
var nome = "Francisco";
var nome = "Antônio";
✕
Não permite redeclaração — let
let nome = "Francisco";
let nome = "Antônio"; // SyntaxError

06 — ESTRUTURAS DE DECISÃO

Estruturas de decisão

A principal estrutura de decisão em programação é o comando IF (SE), de sintaxe simples: ele verifica o resultado do “teste lógico” e, se for verdadeiro, executa os comandos entre chaves { }. Caso contrário, os comandos são ignorados e o programa segue para a próxima instrução.

if (teste_lógico) {
  // comandos executados
  // se o teste for verdadeiro
}
06 — ESTRUTURAS DE DECISÃO

O que é teste lógico?

O comando IF necessita de uma expressão que retorne “verdadeiro (true)” ou “falso (false)”. Basicamente é uma comparação que usa os operadores lógicos a seguir:

Operador Nome Exemplo
>Maior10 > 5
<Menor5 < 10
>=Maior ou igual10 >= 10
<=Menor ou igual10 <= 10
!=Diferente1 != 2
==Igualdade1 == 1

06 — ESTRUTURAS DE DECISÃO

If Else

Podemos incrementar o comando IF com o uso do ELSE, entendido como “caso contrário / se não”.

Os comandos do IF só são executados quando o teste é verdadeiro. E se o valor do teste for falso? Aí entra o ELSE: seus comandos são executados sempre que o teste tiver resultado falso.

if (teste_lógico) {
  // se verdadeiro
} else {
  // se falso
}
06 — ESTRUTURAS DE DECISÃO

Exemplo de If Else

<script>
  var vidas = 3;
  if (vidas > 0) {
    document.write("Jogador vivo");
  } else {
    document.write("Jogador morto");
  }
</script>

07 — VAMOS CODAR
Crie um novo script que leia um número de 1 a 7 e imprima o dia da semana correspondente.
1 = domingo e 7 = sábado.
07 — VAMOS CODAR (RESOLUÇÃO)

Dias da semana com switch

let numero = 2;

switch (numero) {
  case 1: document.writeln('Domingo'); break;
  case 2: document.writeln('Segunda-feira'); break;
  case 3: document.writeln('Terça-feira'); break;
  case 4: document.writeln('Quarta-feira'); break;
  case 5: document.writeln('Quinta-feira'); break;
  case 6: document.writeln('Sexta-feira'); break;
  case 7: document.writeln('Sábado'); break;
  default: document.writeln('O número está fora do intervalo.');
}
